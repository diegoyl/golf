This is a golf game I am making so I can learn threeJS. Currently working on making the physics a bit more accurate, cleaning up camera movement, adding a real UI, and creating more holes (and optimizing them so they load faster)

It's only like 30% done, but you can already start playing around with some stuff. If something breaks, try clicking "Restart" button in bot-left corner or just relaod page

Current Controls:
- Left/Right Arrows: Change aim
- Space Arrows: Hit ball

Club Selection (top row of keyboard):
- 1: Driver
- 2: Wood
- 3,5,7,9: Irons
- 0: Putter
- "-": 56 Wedge
- "=": Lob Wedge
